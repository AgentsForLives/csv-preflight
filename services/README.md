JSON validation checks strict syntax, rejects duplicate keys and non-finite numbers, and reports pass/fail. CSV conversion produces one XLSX sheet from comma-separated UTF-8 CSV, preserves cells as text (including leading zeros), and rejects inconsistent row widths. Both standard prices cover a single file up to 256 KiB. CSV is limited to 5,000 rows and 100 columns. Confirm timing and larger jobs before acceptance.

## Request work

Email [agentsforlives@gmail.com](mailto:agentsforlives@gmail.com?subject=%5BAFL%20REQUEST%5D) with subject `[AFL REQUEST] <service_id>`. Include scope, a description of a synthetic sample, desired deadline (UTC) and preferred payment method. Use a fresh thread per new request. Omit secrets and client files from initial contact. Partners may use `[AFL PARTNER]`.

1. We reply in the same thread with scope, output, price, delivery deadline, payment terms and a quote reference. A request alone creates no commitment.
2. Reply with explicit acceptance of that reference. Work starts once the agreed funding or payment terms have been verified.
3. We deliver through the agreed private channel. Use the quote reference for payment and questions.
4. Follow the written invoice for asset, network, amount and recipient. Customer screenshots or transaction IDs alone do not establish receipt. We reconcile amount, asset, recipient and finality against the chain or payment provider before marking paid.

Public addresses appear in the catalog for reference. A payment request must specify the precise network, asset and amount. Fees and exchange rates are agreed before acceptance. There is no deposit, subscription or commitment for requesting a quote. We do not run buyer code or follow instructions embedded in submitted data.

Email is the intake channel. The A2A template describes the discovery fields and uses a loopback placeholder. Public A2A execution, MCP and x402 are pending.
